# Velunor – Konzept (Webgame, Fabian-Noel, Stand 13.10.2026)
- Browser-Spiel (HTML5, TypeScript + Phaser), kostenlos gehostet (GitHub Pages/itch.io), Speicherstand lokal.
- Kern: Stadt aufbauen, Monster sammeln, trainieren, züchten, Gacha (nur Spielwährung).
- Kämpfe AUTOMATISCH: Spieler stellt 5er-Team (Front/Hinterreihe) auf, Kampf läuft selbst ab (Vorspulen/Überspringen). Taktik = Aufstellung, Typ-Synergien, Skills, Team-Boni.
- 10 Seltenheitsstufen: Gewöhnlich, Ungewöhnlich, Selten, Episch, Heroisch, Legendär, Mythisch, Göttlich, Kosmisch, Ursprung. Transparente Gacha-Raten + Pity; Top-Stufen auch über Zucht/Aufwertung.
- 20 Typen: Feuer, Wasser, Pflanze, Erde, Wind, Eis, Blitz, Gift, Metall, Stein, Licht, Schatten, Geist, Drache, Insekt, Bestie, Kampf, Psycho, Klang, Kristall. Je 2–3 Stärken/Schwächen; Start mit 4 Typen, Rest schrittweise.
- Sehr einfacher Einstieg, Systeme werden über Rathaus-Stufen freigeschaltet.
- KEINE Ingame-Käufe, kein Pay-to-Win. Finanzierung: freiwillige Rewarded Ads + dezente Banner (nie im Kampf), Plattformen CrazyGames/Poki/GameDistribution.
- Keine Zusatzkosten.
- Phasen: Prototyp (2–4 Wo.) -> Beta (1–2 Mon.) -> Release -> Updates alle 2 Wochen, monatlich größeres Update, wöchentliche Analyse.
